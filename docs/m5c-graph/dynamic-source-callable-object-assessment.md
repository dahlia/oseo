===================================

All 66 pinned upstream tests were read at suite revision
`f2d1435644797268dca1f7988cad5a4e89ccd8d2`. The selector matches the
base ledger exactly: 66 unsupported paths owned by the dynamic-source
umbrella. The 2026-10-28 decision, item 1, supplies the accounting rule.

[*callable-object-evidence.ts*](../../tests/native/fixtures/callable-object-evidence.ts).

result. Conversion of Function parameter strings, compilation of its body and
allocation of its dynamic result remain under ADR 0016. No existing reviewed
passing path was assumed to supply a new complete replacement.

partial groups do not close their rows. The 18 fixed groups use both native

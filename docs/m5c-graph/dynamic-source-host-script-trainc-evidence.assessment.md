Dynamic source host Script train C per-path assessment
======================================================

This assessment covers exactly the pinned 98-path train C selector at
bundle 5. Original source and normalized observation digests match the
installed suite and the checked-in exclusion audit. Accounting changes no
observation or dependency tag and never counts an unsupported path as pass.


Method
------

*tests/native/fixtures/host-script-trainc-cases.ts* records every literal
eval call in each original file: its UTF-16 offset, exact call text, cooked
source, whether the call is indirect, the expected completion and the
mutation an original consumer must reject.
*tests/host-script-trainc-source.test.ts* re-derives that table
independently with Babel from the pinned original, whose SHA256 must match.
Every `eval` reference in an original is either such a call or an alias
initializer for indirect calls.

*tests/native/fixtures/host-script-trainc.ts* reads each original file and
replaces only those call expressions, so every other statement, including
each assertion, is kept byte for byte. Only the leading license and
frontmatter comment, up to `---*/`, is omitted. Each call becomes a literal ADR
0029 host Script:

 -  A completion site becomes `__hsCompletion($262.evalScript(...), E)`,
    a strict value and type check that returns the value to the original
    consumer.
 -  An early-error site becomes
    `__hsEarlyError(() => $262.evalScript(...), after)`. The check requires
    `SyntaxError.prototype` identity in the caller's realm, an unchanged
    snapshot of every global own property (key order, value or accessors,
    and attributes, so `eval` too), and an optional caller-side condition;
    it then rethrows, so no later statement runs.
 -  Direct sources in a strict variant get `"use strict"; void 0;` first.
    Indirect sources stay sloppy, as indirect eval is.
 -  A nested literal eval inside an eval source becomes a nested literal
    host Script with the outer source's strictness.

Each variant runs once unmutated and once per mutation index, each in its
own created realm. A mutation replaces one site's completion with a wrong
value, or removes an early-error call. When an original assertion consumes
the site, the mutant bypasses the added check, so the original assertion
must reject it; otherwise the added check must. Either way the verdict is
only `instanceof` the realm's `Test262Error`, never a comparator under
test. `residual-trainc-oracle` separately shows that both checks reject
type confusion, a missing or wrong-type or wrong-realm early error, an
added global, an equal-count global swap, a changed global value or
attribute, a replaced `eval` and a failed caller-side condition.

The structural test compiles each group under both policies and requires
the matched malformed host Scripts to be exactly the expected early-error
literals. The four *tests/host-script-trainc-evidence-N.test.ts* pieces,
registered through *tests/host-script-trainc-evidence.ts*, together run
every fixture once and compare Node.js and Deno references with native
execution under both specialization policies with forced collection.


Conditions
----------

All 64 completion and binding rows call eval at global Script top level, so
the caller context is the global one. The 28 direct early-error rows call
eval from an `assert.throws` callback. Each error is raised while parsing,
before EvalDeclarationInstantiation, and each row's caller statement below
shows that no caller-local state is reachable. The five indirect rows ignore
their caller. Strictness matches in every variant: a strict caller's
strictness is a prepended directive, and a source's own directive is kept.
No row has a hashbang, a module caller, or an arrow, method or
function-context consumer of a caller-local binding.

Differences recorded as unobserved: strict-variant host Script declarations
persist globally where strict eval would keep them local (*let/cptn-value.js*,
*function/cptn-decl.js*, *generators/cptn-decl.js*, *function/name-unicode.js*,
*for/S12.6.3\_A5.js*), and host Script vars are non-configurable where eval
vars are deletable. No original reads or deletes those bindings.

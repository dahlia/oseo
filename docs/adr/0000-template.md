Architecture decision title
===========================

Status
------

Proposed, accepted, superseded, or deferred.


Context
-------

Describe the uncertainty and the downstream contract that needs a decision.


Required contract
-----------------

State what later packages or milestones need to rely on.


Alternatives considered
-----------------------

Include the option to postpone the decision and contain it behind an opaque
boundary.


Probe evidence
--------------

Name the checked-in fixtures, target descriptions, exact tool versions, and
`mise` commands that reproduce the evidence.


Observed results
----------------

Record correctness results and measurements. Separate observed facts from
inferences.


Decision
--------

State the selected contract and its scope.


Consequences
------------

Describe package boundaries, ABI effects, follow-up work, and costs created by
the decision.


Failure modes and replacement triggers
--------------------------------------

Name the evidence that would invalidate the decision or require another probe.


Links
-----

Link dependent, superseding, or superseded records and plans.

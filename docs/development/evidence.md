Evidence
========

The repository stores the [reviewed Test262 results] with the measured
language profiles. The [ECMAScript 2026 profile] explains how the inventory
is counted and distinguishes measured outcomes from gaps. A passing target
cross-link does not constitute a native execution pass.

The [evidence directory] contains the recorded experiments, their conditions,
and the parts of the system they measure. The [contributor guide] explains
how to add or refresh results.
